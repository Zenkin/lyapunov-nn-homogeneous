# Example 2: pendulum stabilization

Stabilization of the upper equilibrium of a nonlinear pendulum.

| Version | Construction |
| --- | --- |
| [`article_version`](article_version) | Printed equations, including the displayed matrix `A` |
| [`corrected_matrix`](corrected_matrix) | Corrected `A`, with frozen `K,P` and then recomputed `P` |
| [`improved`](improved) | Smooth periodic candidate and feedback, with a sampled Lyapunov sublevel |

Each folder documents its numerical choices and validation results.
